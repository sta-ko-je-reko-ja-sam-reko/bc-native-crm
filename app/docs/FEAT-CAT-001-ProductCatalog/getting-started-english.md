# FEAT-CAT-001 - Product Sales Catalog

Present what you sell the way a salesperson thinks about it: products that are ready (or not) to sell, packages
sold as one, and suggestions for what else to offer.

## Manage a product's selling lifecycle

1. Open an **Item** (or **Resource**) card and find the **CRM Catalog** group.
2. Set the **CRM Catalog Status** to *Draft* while you prepare it.
3. Optionally set a **CRM Valid From** / **CRM Valid To** window and a **CRM Default Price List**.
4. When it is ready to sell, choose **Publish** (the status becomes *Active*). Choose **Retire** to withdraw it
   later. Only active products inside their date window are considered sellable.

## Build a bundle

1. Choose the search icon, enter **CRM Bundles**, and open it.
2. Choose **New**, give the bundle a **No.**, **Description** and the **Unit Price** it sells for as one line.
3. Add the **Components** (items or resources) with quantities, and mark each as **Required** or optional. The
   **Component Total** adds up so you can compare it with the bundle price.

## Suggest related products

1. On an **Item** card, choose the **Related Products** action.
2. Add links to other products as **Cross-sell**, **Up-sell**, **Accessory** or **Substitute**, and set a **Rank**
   to control the order suggestions appear in.
